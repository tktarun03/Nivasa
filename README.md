# Nivasa — interiors for Indian homes

A mobile-first interior design web app for the Indian market: discover rooms and regional styles, compare Indian materials, see which codes and standards matter, save mood boards and plan an indicative budget in rupees.

**Version 0.1.0** · Vanilla JavaScript (ES modules) · Vite · no backend, no accounts, no paid APIs.

> **Demonstration content.** Every design is a fictional concept illustrated with original, generated vector art — not photographs of real projects. Budgets are an illustrative model, not quotations. The standards guide identifies documents and marks which ones still need professional verification. Project-specific compliance needs qualified local professionals.

## What's inside

| Page | What it does |
| --- | --- |
| Home | Editorial hero with gentle parallax, featured carousel, personalised picks, style marquee, scrolltelling project story, collections, get-started checklist |
| Explore | Instant search and filters (room, element, style, city, climate, budget, property type, material), sort menu, infinite scroll, refresh and pull to refresh |
| Categories / Category | The full taxonomy — 28 rooms, 23 elements, 12 property types, 11 commercial spaces, 16 styles — with counts and searchable lists |
| Design | Swipeable gallery, full-screen pinch-zoom viewer, photo lock, favourite, save to board, share, specs, materials and indicative budget |
| Collections | Curated sets such as monsoon-ready homes and kitchens for Indian cooking |
| Mood boards | Create, rename and delete boards; drag or button reordering; lock photos and covers; undo |
| Budget planner | Four-step planner with Indian digit grouping (lakh, crore), assumptions, inclusions, exclusions and a print view |
| Materials | 37 materials with uses, pros, cons, care and linked standards; A–Z index; compare up to three |
| Standards | Statutory, model-code, industry and cultural (Vastu) guidance kept separate, each with status and sources |
| Styles | Indian regional and contemporary styles with palettes and materials |
| Settings | Preferences, theme, text size, motion, language, units, haptics, brand name, backup/restore, self-check, version history |
| Interaction patterns | Live demos and notes for every reusable scrolling, animation, loading, gesture, navigation and feedback pattern |

## Run it locally

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # generates illustrations, then builds to dist/
npm run preview      # serve the production build at http://localhost:4173
npm test             # unit tests (Vitest)
npx playwright install chromium   # first time only
npm run test:e2e     # browser tests at 375, 390, 430 px and desktop
npm run lint
```

Requires Node.js 20 or newer.

## Deploy to GitHub Pages

1. In the repository on GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions** (one time).
2. Push to `main`. The *Deploy to GitHub Pages* workflow lints, runs unit and browser tests, builds, and deploys only if everything passes.
3. The site appears at `https://<user>.github.io/<repo>/`. All links are relative, so the repository subpath works without configuration.

## Project structure

```
index.html                 Home entry
pages/<name>/index.html    One real HTML entry per page
src/styles/                tokens, reset, typography, components, animations, responsive
src/js/app.js              Shared boot: preferences, shell, onboarding, service worker
src/js/navigation.js       Page registry, header, adaptive bottom nav, footer
src/js/pages/              One module per page
src/js/components/         Toast, sheets, popover, cards, media, onboarding, board picker
src/js/interactions/       Motion, gestures, pull-to-refresh, infinite list, reorder, A–Z index, swipe actions
src/js/services/           Catalogue search, budget model, favourites, share, haptics, backup, room art
src/js/storage/            Versioned local storage and pure mood-board operations
src/data/                  categories, designs, materials, styles, standards, collections (JSON)
src/i18n/                  en (complete), hi and ta (prepared)
scripts/                   Catalogue seeding, illustration and icon generation
public/                    Manifest, icons, service worker, generated illustrations
tests/unit, tests/e2e      Vitest and Playwright
```

See [AGENTS.md](AGENTS.md) for conventions, [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the data model, [docs/INTERACTION-PATTERNS.md](docs/INTERACTION-PATTERNS.md) for the pattern library, [ROADMAP.md](ROADMAP.md) and [CHANGELOG.md](CHANGELOG.md).

## Privacy

Everything you save stays in your browser's local storage. Nothing is sent anywhere. Use **Settings → Save backup file** to move data between devices.
